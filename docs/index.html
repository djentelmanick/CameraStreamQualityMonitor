Стек
Из чего собран проект

Все компоненты запускаются одной командой через Docker Compose.

🐍

RTSP Exporter

Кастомный Python-экспортёр. RTSP OPTIONS probe, Digest-авторизация для Hikvision, метрики latency / jitter / bitrate.

📡

Blackbox Exporter

ICMP ping, TCP check RTSP-порта и ONVIF-порта, HTTP 2xx. Все результаты — в VictoriaMetrics.

⚡

VictoriaMetrics

Prometheus-совместимое хранилище метрик. Скрейп раз в секунду, совместим с PromQL.

📊

Grafana + Grafana Live

Дашборд с stat-панелями, heatmap, gauge и SLA uptime. Grafana Live — WebSocket push от экспортёра для обновления панелей без задержки scrape-цикла.

🔧

Config API

FastAPI CRUD для управления списком камер. Авто-reload экспортёра при изменении конфига.

🖥

Config UI

React + Vite SPA на Nginx. Добавление, редактирование, удаление камер с live-обновлением.

Метрики
Что собирает экспортёр

Каждая метрика несёт лейблы camera, host, location, building.

Метрика Тип Описание
camera_up gauge Доступность камеры: 1 = онлайн, 0 = офлайн
camera_rtsp_latency_ms gauge Задержка RTSP-подключения (мс)
camera_rtp_packet_loss_ratio gauge Доля потерянных RTP-пакетов (0..1)
camera_rtp_jitter_ms gauge Джиттер RTP (мс)
camera_stream_bitrate_kbps gauge Битрейт видеопотока (кбит/с)
probe_success blackbox TCP/ICMP доступность (1 = успех)
probe_duration_seconds blackbox Время выполнения пробы

Запуск
Быстрый старт

Docker Engine ≥ 20.10 и Docker Compose ≥ 2.0. Три команды — и весь стек поднят.

1

Клонировать репозиторий

Скопировать проект к себе на машину.

2

Собрать и запустить стек

Одна команда поднимает все 8 сервисов: mock-камеры, экспортёры, VictoriaMetrics, Grafana, Config API и UI.

3

Открыть Grafana

Дашборд доступен сразу — datasource и panels инициализируются автоматически через provisioning.

# 1. Клонировать git clone https://git.miem.hse.ru/nvpliasov/1-3-blackbox-exporter.git cd 1-3-blackbox-exporter # 2. Запустить весь стек docker compose up --build -d # 3. Проверить статус docker compose ps

Как устроен стек

Все компоненты работают в одной Docker-сети и общаются по именам сервисов.

Mock-камеры (×3, RTSP :8554–:8556) │ ├──► rtsp-exporter :9115 Python · RTSP OPTIONS + Digest · метрики latency/jitter/loss/bitrate │ │ │ ├──► VictoriaMetrics :9090 pull scrape · Prometheus API · VMUI │ │ │ │ │ └──► Grafana :3000 (scrape-путь, ~1 с) │ │ │ └──► Grafana Live WebSocket push · real-time · без задержки scrape-цикла │ └──► blackbox-exporter :9116 ICMP ping · TCP RTSP · TCP ONVIF · HTTP 2xx │ ▼ VictoriaMetrics ──► Grafana Config UI :8080 (React + Nginx) │ REST /cameras ▼ Config API :8000 (FastAPI) ──► POST /reload ──► rtsp-exporter │ bind mount ▼ exporter_config.yml
